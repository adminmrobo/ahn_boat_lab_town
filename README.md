# Ahn Lab Town — 업데이트 방법

## 폴더 구성
- `index.html` — 연구실 페이지 (코드는 건드리지 않아도 됩니다)
- `projects.csv` — 완료 / 진행중 / 예정 작업 목록 (엑셀로 수정)
- `projects.html` — 작업 진행 페이지
- `ost/` — 공간별 OST 음악과 순서표 `ost/ost.csv`
- `servers.csv` — 지하 1층 서버실 랙 내용 (별도 repo 주소를 넣으면 그쪽 파일을 우선 읽음)
- `research.json` — 박사 연구실적 (GitHub 페이지, 논문, 특허, 저서)
- `config.json` — 공유 카운터 주소, 텔레그램 봇 주소, 박사 소개 링크 2개
- `assets/` — 맵, 캐릭터 포즈(27종), 사고 컷, 표정 96장(`assets/expr/`, fruitfly-lab-expressions 저장소 기준)
- `counter_apps_script.gs` — 방문자 전체 누적 집계용 구글 시트 코드

## 연구실적 추가하기 (research.json)
GitHub에서 `research.json`을 열고 연필(편집) 아이콘을 누른 뒤, 같은 묶음 안의 항목 한 줄을 복사해 붙이고 내용만 바꾸면 됩니다.

```json
{"title": "새 강의 페이지 제목", "url": "https://adminmrobo.github.io/새저장소/", "desc": "시리즈 이름"},
```

논문은 `papers` 묶음에 `date`, `title`, `venue`, `url`을 넣습니다. 쉼표(,)를 빠뜨리면 페이지가 내장된 예전 목록을 보여 주니, 저장 전에 항목 사이 쉼표를 확인하세요. 맨 위 `updated` 날짜도 바꿔 주세요.

## 작업 진행 현황 바꾸기 (projects.csv)
랩타운과 작업 진행 페이지(projects.html)는 모두 `projects.csv` 하나를 읽습니다. 엑셀에서 열어 고치고 **CSV로 저장**한 뒤 GitHub에 올리면(같은 이름으로 덮어쓰기) 바로 반영됩니다. 엑셀 기본 저장 방식(한글 ANSI)과 UTF-8 둘 다 읽습니다.

| 열 | 쓰는 법 |
|---|---|
| 상태 | `완료` / `진행중` / `예정`. 비우면 날짜로 자동 판단 (완료일 지남 → 완료, 시작일 전 → 예정, 그 사이 → 진행중) |
| 카테고리 | 자유롭게. 페이지 위 필터 버튼이 자동으로 생깁니다 |
| 프로젝트명 | 필수. 비어 있는 줄은 건너뜁니다 |
| 프로젝트링크 | 있으면 제목이 링크가 됩니다 |
| 시작일 / 완료일 | `2026-11-01`, `2026.11.01`, `2026/11/01` 모두 가능. 예정일이어도 됩니다 |
| 담당 | `박사` / `조수` / `초파리 연구원` / `Money-Robo`. 랩타운에서 그 캐릭터가 이 작업을 말합니다 (비우면 박사) |
| 진행률 | 0~100. 비우면 진행중 작업은 시작일·완료일로 자동 계산 |
| 비고 | 자유 메모 |
| 프로젝트명_en, _zh, _ja, _uz, _ru | 선택. 비우면 그 언어에서도 한국어 제목이 보입니다 |

## 텔레그램 조교 봇
지금은 "준비 중"으로 보입니다. 봇이 열리면 `config.json`의 `TELEGRAM_BOT_URL`에 `https://t.me/봇아이디`를 넣으세요. 랩타운 상단 버튼, 조수 자리, 작업 진행 페이지의 버튼이 모두 바로 연결로 바뀝니다.

## 방문자 전체 클릭·사고 건수 누적하기
지금은 방문자 각자의 브라우저 안에서만 누적됩니다. 모든 방문자의 합계를 쌓으려면:
1. 구글 시트를 새로 만들고 [확장 프로그램] → [Apps Script]를 엽니다.
2. `counter_apps_script.gs` 내용을 붙여넣고 저장합니다.
3. [배포] → [새 배포] → 웹 앱 / 실행 사용자: 나 / 액세스: 모든 사용자 → 배포.
4. 나온 주소(…/exec)를 `config.json`의 `COUNTER_URL`에 넣습니다.

시트의 `log` 탭에 실험 시각·종류·출력 레벨·결과(성공/사고/대박)가 한 줄씩 쌓입니다. 이미 배포한 스크립트가 있다면 새 코드로 바꿔 붙이고 [배포 관리]에서 새 버전으로 다시 배포하세요.

## 언어
한국어가 기본이며 위·아래 언어 선택창에서 English, 中文, 日本語, Oʻzbekcha, Русский로 바꿀 수 있습니다. 주소 끝에 `#en`, `#ja`처럼 붙이면 그 언어로 바로 열립니다.

## 엘리베이터 · 지하 1층 서버실
연구실 출입문(아래쪽 양문)으로 나가면 엘리베이터 홀이 있습니다. 엘리베이터에서 고를 수 있는 층은 1층(연구실)과 지하 1층(서버실)뿐이고, 옥상·3층·2층·지하 2~4층은 "접근 금지 구역"으로 표시됩니다. 서버실의 "이세계 던전" 입구도 접근 불가입니다.

서버실의 랙 10개는 CSV의 **카테고리 순서대로** 이름이 붙고, 같은 카테고리의 줄이 그 랙의 내용물이 됩니다. 카테고리가 10개보다 적으면 남는 랙은 "빈 랙"으로, 11번째부터는 표시되지 않습니다.

| 열 | 쓰는 법 |
|---|---|
| 카테고리 | 랙 이름. 처음 나온 순서대로 RACK 01~10에 배정 |
| 제목 | 필수 |
| 내용소개 | 한두 문장. 주소(https://…)를 넣으면 자동으로 링크가 됩니다 |
| 해시태그 | `#머신러닝 #회귀`처럼 띄어쓰기로 구분 (# 없이 써도 붙여 줍니다) |
| 생성일 | `2025-07`, `2025-07-01`, `2025` 등 자유 |
| 비고 | 자유. 주소를 넣으면 링크가 됩니다 |

### 서버실 내용 번역 (선택)
언어별 열을 추가하면 그 언어로 볼 때 해당 칸이 표시되고, 비어 있으면 한국어가 그대로 보입니다. 열 이름은 `원래 열 이름_언어코드` 형식입니다.

- 언어코드: `en`(English) · `zh`(中文) · `ja`(日本語) · `uz`(Oʻzbekcha) · `ru`(Русский)
- 예: `카테고리_en`, `제목_en`, `내용소개_en`, `해시태그_en`, `비고_en`, `제목_ja` …
- 카테고리 번역은 그 카테고리의 첫 줄에만 적어도 랙 이름에 적용됩니다.
- 순서는 상관없지만, 기본 6개 열(카테고리~비고) 뒤에 붙이는 것을 권장합니다.

지금 들어 있는 27건은 5개 언어 번역이 모두 채워져 있습니다. 새 항목을 추가할 때 번역 칸을 비워 두면 그 항목만 한국어로 보입니다.

### 별도 repo로 관리하기
1. 새 저장소(예: `floor_b01`)를 Public으로 만들고 `servers.csv`를 올립니다.
2. 저장소에서 servers.csv를 열고 **Raw** 버튼을 눌러 나온 주소를 복사합니다. 예: `https://raw.githubusercontent.com/adminmrobo/floor_b01/main/servers.csv`
3. 랩타운 저장소의 `config.json`에서 `SERVER_CSV_URL`에 그 주소를 넣습니다.
이후에는 서버실 저장소의 servers.csv만 고치면 랩타운에 반영됩니다(GitHub 캐시 때문에 최대 5분 정도 걸릴 수 있음). 주소를 비워 두거나 읽기에 실패하면 랩타운 폴더의 servers.csv를 대신 읽습니다.

## OST (공간별 배경음악)
1층 연구실과 지하 1층 서버실은 각자 재생 목록을 가지며, 순서대로 재생하고 마지막 곡이 끝나면 처음으로 돌아갑니다. 엘리베이터로 층을 옮기면 음악이 부드럽게 바뀝니다. 브라우저 규칙상 방문자가 **♪ OST 켜기**를 눌러야 소리가 나며, 한 번 켜면 다음 방문 때 첫 클릭과 함께 다시 재생됩니다.

1. 음악 파일(mp3 권장, 곡당 5MB 이하)을 `ost/` 폴더에 올립니다.
2. `ost/ost.csv`에 한 줄씩 적습니다.

| 열 | 쓰는 법 |
|---|---|
| 공간 | `1F`(연구실) 또는 `B1`(서버실). 나중에 층이 열리면 그 층 코드를 쓰면 됩니다 |
| 순서 | 1, 2, 3… 작은 수부터 재생 |
| 제목 | 화면에 "지금 재생"으로 보일 이름 |
| 파일 | `ost/` 안의 파일 이름. 다른 곳의 전체 주소(https://…)도 가능 |
| 비고 | 자유 메모 |

지금 들어 있는 4곡(Night Lab Shift, Coffee Break Loop, Server Hum, Rack Lights)은 시험용으로 직접 만든 짧은 칩튠이라 자유롭게 바꾸셔도 됩니다. 다른 저장소에 음악을 두려면 `config.json`의 `OST_PLAYLIST_URL`에 그 저장소 ost.csv 주소를 넣으면 되고, 파일 이름은 그 ost.csv 위치를 기준으로 찾습니다.

## 표정 (fruitfly-lab-expressions)
캐릭터 4명 × 표정 24종(E01~E24)을 대화창과 머리 위 말풍선에 씁니다.
- 대화할 때마다 대사에 맞는 표정으로 초상이 바뀌고, 머리 위에 같은 표정 말풍선이 뜹니다.
- 대화창의 **😀 표정 24종** 버튼으로 표정 전체를 보고, 누르면 그 표정의 대사를 말합니다(6개 언어).
- 연구원을 **빠르게 세 번** 누르면 뿔남·삐짐·당황·멍·폭포 눈물 중 하나로 반응합니다.
- 실험 카운트다운 중에는 긴장한 표정, 사고 때는 충격·폭포 눈물, 대박 때는 반짝눈, 성공 때는 기쁨 표정이 뜹니다.
- 가만히 있어도 가끔 연구원 머리 위에 생각·졸림·멍 같은 표정이 떠오릅니다.

표정 저장소의 그림을 바꾸면 `assets/expr/{캐릭터}_{E번호}.webp`(초상)와 `{캐릭터}_{E번호}_f.webp`(얼굴)를 같은 이름으로 교체하면 됩니다. 캐릭터 키: doc(박사) · asst(조수 하루) · fly(초파리) · robo(Money-Robo).
